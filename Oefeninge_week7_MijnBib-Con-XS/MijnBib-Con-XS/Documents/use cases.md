 # Use cases

 Er zijn 4 use cases. use case 2 en 3 zijn onafhankelijk van elkaar en use case 1 wordt uitgevoerd aan de start van use case 2 en 3. Use case 4 wordt aan het einde van use case 2 en 3 uitgevoerd.
De use case user is een lid.
